# DUKA SMART ELECTRONICS
## Retail Sales & Customer Intelligence Using PostgreSQL

## Project Overview

This project focuses on analysing retail sales and customer purchasing behaviour for Duka Smart Electronics using PostgreSQL.

The objective is to transform raw transactional data into meaningful business insights that can support informed decision-making, improve customer understanding, and strengthen sales performance.

Through SQL queries, the project explores customer activity, order patterns, payment methods, revenue generation, and overall retail performance.

This project was undertaken as part of the **LuxDevHQ Data Science, Analytics and AI Programme – Cohort 9**.

## Project Objectives

The main objectives of this analysis are to:

- Examine and understand the structure of the retail database.
- Analyse customer purchasing behaviour.
- Identify sales and order trends.
- Evaluate revenue and transaction performance.
- Investigate customer payment preferences.
- Identify valuable customers and purchasing patterns.
- Generate actionable business recommendations.

## Dataset Description

The project dataset consists of retail transaction records containing customer and order information.

| Dataset Metric | Description |

## Analytical Approach

The analysis involved several SQL techniques, including:

1. **Data Exploration:** Understanding database tables, columns and relationships.
2. **Filtering:** Using WHERE to retrieve specific records.
3. **Aggregation:** Applying SUM, COUNT, AVG, MIN and MAX.
4. **Grouping:** Using GROUP BY and HAVING to summarise business data.
5. **Joins:** Combining related tables to answer business questions.
6. **Subqueries and CTEs:** Breaking down complex analytical problems.
7. **Window Functions:** Analysing rankings, customer activity and transaction patterns.
8. **Business Intelligence:** Translating query results into meaningful business recommendations.
